# Scenario TEAM

هذا المشروع هو موقع ويب ثابت لتجهيز وجرد قسم السيناريو تيم.

## التشغيل محليًا

```bash
python -m http.server 8000
```

ثم افتح المتصفح على:

```text
http://localhost:8000
```

## النشر على GitHub Pages

1. ارفع المشروع إلى مستودع GitHub.
2. من إعدادات المستودع، افتح قسم Pages.
3. اختر Source: GitHub Actions.
4. اضغط Save.
5. سيتم النشر تلقائيًا عند كل push إلى الفرع `main`.

## ملاحظات

- المشروع يعمل بالكامل كـ HTML/CSS/JS ثابت.
- لا يحتاج إلى Node.js أو backend.
