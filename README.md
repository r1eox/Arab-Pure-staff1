# Unified Admin Dashboard

هذا المشروع يعمل كـ Dashboard موحد يجمع بين:

- EVENTS-TEAM
- INTERVIEWS-OFFICIAL
- RAQABH
- ROLES-OFFICIAL
- Senario-TEAM
- BAN-TEAM

## مبدأ العمل

- تم الحفاظ على كل قسم كـ مشروع مستقل داخل مجلده الخاص.
- تم إنشاء واجهة موحدة (Shell) فقط لتصفح الأقسام.
- تم إعداد نظام LocalStorage مع Prefix لكل قسم لتجنب تضارب المفاتيح.

## التشغيل

افتح ملف `index.html` في المتصفح مباشرة.

## ملاحظات

- لا يتم تعديل تصميم الأقسام الأصلية.
- كل قسم يفتح داخل iframe داخل اللوحة الرئيسية.
- يمكن توسيع المشروع لاحقاً لإضافة صلاحيات لكل قسم.
